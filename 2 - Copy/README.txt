THE ART OF NATURE - Interactive Exhibition Prototype

FILES
- index.html       Homepage
- about.html       About the Exhibition
- artists.html     Artists' Statements
- gallery.html     Interactive Gallery
- style.css        Responsive styling
- script.js        Navigation, zoom modal, speech audio, and 360 drag interaction

HOW TO RUN
1. Extract the ZIP.
2. Open index.html in Chrome, Edge, or Firefox.
3. No server or installation is required.

INTERACTIVE FEATURES
- Six artworks displayed in a responsive CSS Grid.
- Click an artwork image to open a zoom-style modal.
- Audio descriptions use the browser's Web Speech API.
- The 360 Nature Study is a drag-to-rotate prototype.
- Mobile navigation collapses into a menu.

NOTE
The artwork visuals are CSS-generated prototype artwork, so the project is self-contained and works offline.
