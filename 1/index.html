Multimedia Concepts

Images

Images are visual multimedia data used to present destinations and attractions. JPEG is used because it provides good image quality while reducing file size.

Audio

Audio provides spoken information from the travel agent. MP3 compression reduces the file size while maintaining acceptable sound quality.

Video

Video combines images and audio over time to demonstrate a tourist attraction. MP4 is commonly used for efficient multimedia distribution.

Compression

Compression reduces the amount of storage required by multimedia files. JPEG uses lossy compression, which removes some visual information that is less noticeable to human viewers.

File Formats

JPEG is used for photographs, MP3 for compressed audio, and MP4 for video. Different formats are selected according to the type of multimedia data.

Data Representation

Digital multimedia represents images, audio and video as binary data. This allows computers to store, process and transmit multimedia content.
